# github-training-project
# مشروع التدريب الميداني - تطوير واجهة مستخدم (Profile Card)

##  وصف المشروع
موقع ويب شخصي بسيط (Profile Card) يعرض المعلومات الأساسية للمستخدم مع واجهة تفاعلية تدعم الوضع المظلم (Dark Mode). تم بناء هذا المشروع كجزء من متطلبات التدريب الميداني لإتقان أدوات Git و GitHub.

##  التقنيات المستخدمة
* **HTML5**: لبناء هيكل الصفحة.
* **CSS3**: لتصميم الواجهة وتنسيق الألوان (Responsive Design).
* **JavaScript**: لإضافة التفاعل وتبديل الوضع المظلم (Dark/Light Mode).
* **Git & GitHub**: لإدارة النسخ والعمل على الفروع (Branching).
